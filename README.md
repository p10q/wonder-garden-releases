# Wonder Garden for Mac

Wonder Garden is free to download and use. Twelve offline picture games and toddler Keyboard Play are included, with no ads or in-app purchases. Requires macOS 14 or later; supports Apple silicon and Intel Macs.

Download the signed, notarized DMG from the latest release, open it, and drag Wonder Garden into Applications.
